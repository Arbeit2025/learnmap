# learnmap

テーマを入力すると、そのテーマを学ぶための**知識マップ**（ノードのつながり）を表示する小さな学習支援ツールです。「Learn Anything」のような、全体像から学び始めるための地図をイメージしています。

## 使い方

1. トップページで学びたいテーマを入力するか、収録テーマのチップを選ぶ
2. マップが「前提 → 基礎 → 核心 → 応用 → 実践」の段階ごとに表示される
3. ノードをクリックすると、その項目の説明と学習リソース（Wikipedia・公式ドキュメント等）へのリンクが表示される
4. 学び終わったノードには「学習済み」チェックを付けられる（チェックはブラウザの localStorage に保存され、次回開いたときも残る）

## 収録テーマ（24件）

Python / Web開発 / 機械学習 / データ分析 / 英語 / 数学 / 統計学 / 物理学 / 化学 / 歴史 / デザイン / 写真 / 動画編集 / 音楽理論 / 料理 / 簿記 / 会計 / マーケティング / 心理学 / 経済学 / 法律入門 / 哲学 / プログラミング基礎 / 文章術

各テーマに段階つきノード8〜10件を収録しています。

## 未収録テーマについて

知識ベースにないテーマを入力すると、汎用テンプレート（入門 → 基礎概念 → 仕組み → 応用 → 実践の5段階）でマップを生成します。各ノードには Wikipedia の検索リンク等を付けています。画面上にも「登録外テーマ向けの汎用マップ」であることを明記しています。

## 技術構成

- Python / Flask（単一ファイル `app.py`、知識ベースも同ファイル内のデータ構造）
- マップ描画はサーバー側で生成する SVG（JavaScript ライブラリ不使用）
- 学習済みチェックとライト／ダーク切替はブラウザの localStorage に保存
- デプロイ想定：Render Free（`render.yaml`、gunicorn で起動）

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://127.0.0.1:5000/
```

## テスト

